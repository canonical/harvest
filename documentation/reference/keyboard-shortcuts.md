# Keyboard shortcuts

Chat panes and Code session workspaces. Shortcuts act on the focused pane.

| Shortcut | Action |
|---|---|
| `Ctrl+Alt+T` | new tab |
| `Ctrl+Alt+\` | split right |
| `Ctrl+Alt+-` | split down |
| `Ctrl+Alt+W` | close tab |
| `Enter` | send message |
| `Shift+Enter` | new line in the message |
| `Ctrl+V` | paste an image as an attachment |
| `Escape` | close a menu or dialog |

Menus support the arrow keys. Every control can be reached with `Tab`.
