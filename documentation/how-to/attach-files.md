# Attach images and PDFs

**Goal:** ask about a screenshot, a diagram or a document.

Select the paper-clip button in the message box, or paste an image with `Ctrl+V`. Supported: PNG, JPEG, GIF, WebP and PDF. Attachments show as chips above the message; select **×** on a chip to remove it.

The model must support images or documents; most current Anthropic, Gemini and OpenAI models do.
