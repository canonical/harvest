# Ask about a specific repository or version

**Goal:** get an answer about exactly the code you mean.

Name the repository, and the version when several are indexed:

> In `itsdangerous` at `main`, where is the default salt set?

> Compare `TimestampSigner.unsign` between `cinder` versions `stable/2024.1` and `unmaintained/2024.1`.

Without a name, the agent lists the repositories you can access and picks the most likely one; its first steps (*Show steps*) show which. In a Code session, questions are about the session's project unless you name another repository.

You can only ask about repositories you can access: see [Control who sees which repositories](repository-access.md).
